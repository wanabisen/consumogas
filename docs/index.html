¿Cómo consigo el token? (solo la primera vez)
  1. Entra en GitHub → Fine-grained token.
  2. Nombre: Dashboard gas. Caducidad: la que quieras (p. ej. 1 año).
  3. Repository access: Only select repositories → consumogas.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Generate token, cópialo y pégalo aquí. Solo da acceso a este repositorio.
